## 6. Jak sprawdzać w kontenerze Linux (sprawdzone)

- `bun install`, `bun run storybook` (port 6006), zrzuty przez Playwright (`chromium.launch()` bez opcji).
- `bun run test:storybook` w kontenerze wymaga przeglądarki z `/opt/pw-browsers/chromium`: lokalna kopia configu z
  `playwright({ launchOptions: { executablePath: "/opt/pw-browsers/chromium" } })` — nie commitować.
- Pełny check: `bun run lint`, `bun run typecheck`, `bun run test` (~7 min na Linuksie), `bun run test:storybook`.
